# Bosonic Quantum State 

A Python implementation for representing and evolving bosonic quantum states in the Fock basis.

This project provides a `BosonicQuantumState` class that can be used to build multi-mode bosonic states, apply creation and annihilation operators, evolve states through a linear optical unitary transformation, and compute output probabilities.

## Features

- Represent bosonic Fock states as sparse dictionaries
- Create vacuum states and single basis states
- Apply bosonic creation and annihilation operators
- Evolve quantum states through a unitary matrix
- Compute state norms and output probabilities
- Normalize quantum states
- Add states and multiply them by complex scalars
- Display quantum states in readable Dirac notation

## Notes
This is a first version of the code. It is mainly intended for testing, learning, and small simulations.
Please do not trust the results blindly yet. If you find a bug, unexpected behavior, or an incorrect result, please open an issue or report it.
